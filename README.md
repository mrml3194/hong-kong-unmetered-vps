## “不限流量”有四种写法，先认清楚再比价

同样是这四个字，背后是四套完全不同的做法。看懂这四家，后面看任何一家的套餐表都不会被绕进去。

判读方法就一句：看到“不限流量”，先找端口带宽这个数，再看超额后是否降速、带宽是独享还是共享。这三项清楚了，价格才有可比性。

## 线路：所谓“三网直连”，每家说的不是一回事

香港到大陆的物理距离摆在那里，三网直连的情况下延迟普遍在 30～50ms，欧美机房动辄 200ms 以上，这个差距比任何优化宣传都实在。香港机房带宽成本高于美国，同配置的香港机器贵一截属于行业常态。

问题在“三网直连”这四个字没有统一定义。恒创精品线是去程分开走：电信从上海网口出境走 59.43 的 CN2 GIA，联通走 AS4837，移动走 CMI 骨干，三网各走各的，回程再回香港机房。丽萨的 CMI 线是去程电信 CN2、联通 AS9929（CUII）、移动 CMIN2，回程三网统一走 CMI 大陆优化，宣称国内主流城市平均延迟 50ms 以内。

Akile 的香港原生 IP 产品线 HKPro 官方描述是“多线接入，CN2GIA CUG CMI”。第三方路由追踪显示：回程电信走 CN2、联通走 CUG（AS10099 接 AS9929）、移动走 CMI；去程电信和联通都走 CUG，移动走 CMI。也就是说，它的“三网优化”里电信联通的去程是同一段 CUG 出境，和恒创那种电信单独走 CN2 GIA 的去程不是同一套东西。问客服的时候，“去程走什么、回程走什么”要分开问，只答“三网直连”等于没答。

表里那三档 HKBGP-UNLIMITED 的名字只说明走 BGP，公开页面没写具体接哪几条大陆线路，对延迟敏感的业务，下单前把这个问题问清楚。

## 常见问题

**不限流量真的不会限速吗？**
看写法。端口定死型（Akile HKBGP 三档、丽萨不限流量档）的“限速”就是端口本身，100M 的机器不会给你 200M。额度降速型（DMIT T1）用完月额度后掉到 50Mbps 或 100Mbps，不停机。公平使用型（海外 1Gbps 方案）没有硬上限，但长期占满共享端口会被干预。极低带宽型（恒创 2Mbps）从第一天就是这个速度。

**2Mbps 能干什么？**
约 250KB/s，跑满一个月理论流量约 648GB。纯文字站、小图站、监控探针、SSH 常驻够用，视频和下载站不用考虑。

**100M 不限流量一个月到底能跑多少？**
理论上限约 32TB，前提是 24 小时持续跑满。实际业务能到 5～10TB 就算用得狠了。

**香港 VPS 要备案吗？**
不用。香港不在大陆备案监管范围内，建站可以直接上线。

**流量是单向算还是双向算？**
要看清。Akile 部分香港产品（如 HKBase 系列）标的是 In+Out，进出都计。上表七档不限流量不受这条影响，但买限量档时这条直接决定实际可用量。

**能退款吗？**
已有明确 48 小时退款承诺的是丽萨主机那条线。Akile 的退款条款在付款前向客服确认一遍，别默认。
